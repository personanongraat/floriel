# Флориэль

Витрина с каталогом, конструктором букетов, корзиной, кабинетом флориста и отправкой заявок в Telegram и на почту. Серверная часть работает на PHP.

## Проверка на компьютере

Запустите `start.cmd` на Windows, если PHP есть в PATH. То же самое в терминале из папки проекта:

```sh
php -S 127.0.0.1:4173 -t public_html
```

Откройте http://127.0.0.1:4173/. Кабинет доступен по адресу http://127.0.0.1:4173/admin/. При локальном запуске без файла настроек пароль кабинета — `floriel-demo`. Для реальной отправки сообщений с компьютера PHP тоже потребуются cURL и работающий почтовый транспорт.

## Загрузка на Timeweb

1. Скачайте ZIP репозитория и распакуйте его. В Timeweb создайте отдельный сайт и откройте его папку через файловый менеджер.
2. Загрузите содержимое `public_html/` в `public_html/` этого сайта. Папку `backend/` загрузите рядом с `public_html/`, в папку сайта. Если в новом `public_html/` есть стартовая страница хостинга, замените её. На сайте включите PHP 8.3 или новее и HTTPS.
3. Сделайте копию `backend/config.example.php` с именем `backend/config.php`. Укажите свой пароль кабинета, токен от @BotFather, ID чата, почту получателя и разрешённый хостингом адрес отправителя. Для личного чата нажмите «Старт» в боте. Для группы добавьте бота и отправьте ему команду. ID чата можно взять из поля `message.chat.id` ответа Telegram Bot API `getUpdates`.
4. Откройте сайт по HTTPS и войдите через «Войти как флорист» или по адресу `/admin/`. Проверьте сохранение букета, отправьте пробный заказ и убедитесь, что сообщения пришли в Telegram и на почту. PHP использует cURL и `mail()`. Доступность `mail()` на пробном аккаунте Timeweb можно уточнить у поддержки.

Папка `data/` создаётся рядом с `public_html/` при первом действии, которому нужна запись. В ней хранятся изменения каталога, загруженные фотографии и статусы отправки. При обновлении сайта сохраняйте `data/` и `backend/config.php`. Если переносите данные из прежней версии, сохраните также старые фотографии из `public/uploads/` в `public_html/uploads/`.
