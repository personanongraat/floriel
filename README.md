# Флориэль

Витрина цветочного салона с каталогом, конструктором букетов, корзиной и кабинетом флориста.

## Запуск на компьютере

Запустите `start.cmd` в Windows или выполните `node server.mjs` с Node.js 22+. Витрина доступна по адресу http://127.0.0.1:4173, кабинет флориста — по адресу http://127.0.0.1:4173/admin#catalog.

Локальный пароль кабинета — `floriel-demo`. После входа можно добавлять, редактировать, скрывать и удалять букеты прямо в каталоге. Каталог сохраняется в `data/catalog.json`, загруженные фотографии — в `public/uploads/`.

## Подключение заявок

PHP отправляет заказ или отзыв через Telegram Bot API и почтовый транспорт сервера. При повторной попытке с теми же данными отправка повторяется для канала, который ещё не подтвердил приём. Письмо содержит полный состав заказа, а в Telegram длинный заказ может отображаться сокращённо.

1. Установите PHP CLI 8.3+ с расширением cURL и настройте почтовый транспорт PHP (`mail()`). Для Linux-хостинга это обычно локальный почтовый агент или настроенный SMTP-релей через `sendmail_path`.
2. Создайте бота через @BotFather. Для личного чата нажмите «Старт» в диалоге с ботом. Для группы добавьте бота и отправьте ему команду. Возьмите `message.chat.id` из ответа метода Telegram Bot API `getUpdates`, выполнив запрос в доверенной среде.
3. Скопируйте `.env.example` в `.env`. Укажите токен бота, ID нужного чата, адрес получателя и разрешённый почтовым транспортом адрес отправителя. Укажите также пароль кабинета. Если PHP отсутствует в PATH, задайте полный путь в `FLORIEL_PHP_BIN`.
4. Запустите `node --env-file=.env server.mjs`. Оформите пробный заказ и отправьте отзыв после него. Проверьте сообщения в Telegram и во входящей почте.

## Размещение

Сайт рассчитан на сервер с Node.js и PHP CLI. Перед публичным запуском задайте `NODE_ENV=production`, установите уникальный пароль кабинета и настройте HTTPS через обратный прокси на порт 4173. Ограничьте частоту запросов на `/api/orders`, `/api/feedback` и `/api/login` на прокси. Сохраняйте `data/` и `public/uploads/` между обновлениями. В `data/form-receipts/` хранятся номера заявок, контрольные суммы и статусы отправки. Секреты задаются в окружении сервера или в локальном `.env`.
